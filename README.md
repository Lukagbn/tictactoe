# Tic Tac Toe

A simple, responsive Tic Tac Toe game built with React, TypeScript, and Sass.

## Features

- Classic 2-player Tic Tac Toe
- Custom CSS-drawn X and O marks
- Winner overlay + start screen
- Responsive on mobile and desktop

## Tech Stack

React · TypeScript · Sass · Vite

## Project Structure

```
src/components/
├── Circle/   # O mark
├── Cross/    # X mark
└── Winner/   # Win overlay
```

## Getting Started

```bash
git clone <your-repo-url>
cd <project-folder>
npm install
npm run dev
```
